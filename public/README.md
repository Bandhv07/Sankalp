# Sri Hanuman Chalisa & Sankalpam Tracker (iOS & Web PWA)

This repository contains both the native Android app and the complete **Progressive Web App (PWA)** for iPhone, iPad, Android, and Desktop, deployable directly with **GitHub Pages**.

## Live GitHub Pages Deployment Guide

To host this app for free on your iPhone or share with others:

1. In your GitHub repository, go to **Settings** -> **Pages** (in the left sidebar).
2. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `master` (or `main`)
   - **Folder**: Select `/public` (or `/root` if using gh-pages branch)
3. Click **Save**.
4. Within 1–2 minutes, GitHub will give you a live URL like:
   `https://<your-username>.github.io/<repo-name>/`

## How to Install on iPhone / iPad (iOS):
1. Open your GitHub Pages URL in **Safari**.
2. Tap the **Share** button (the square with an arrow pointing up).
3. Scroll down and tap **"Add to Home Screen"**.
4. Tap **Add** in the top right corner.
5. The app will launch like a native iOS application in full-screen mode, with offline support, local persistence, haptic touch, audio chime, and the full 40 Chaupais and 11-day Sankalpam.
